torchrecurrent.PeepholeLSTMCell

class torchrecurrent.PeepholeLSTMCell(input_size, hidden_size, bias=True, activation_fn=<built-in method tanh of type object>, gate_activation_fn=<built-in method sigmoid of type object>, kernel_init=<function xavier_uniform_>, recurrent_kernel_init=<function xavier_uniform_>, peephole_kernel_init=<function normal_>, bias_init=<function zeros_>, recurrent_bias_init=<function zeros_>, device=None, dtype=None)

A Peephole LSTM cell with learnable peephole connections.

This LSTM variant adds element-wise “peephole” terms from the cell state into the input, forget, and output gates.

\[\begin{split}\mathbf{z}(t) &= \tanh\Bigl( \mathbf{W}_{ih}^{z}\,\mathbf{x}(t) + \mathbf{b}_{ih}^{z} + \mathbf{W}_{hh}^{z}\,\mathbf{h}(t-1) + \mathbf{b}_{hh}^{z} \Bigr), \\[6pt] \mathbf{i}(t) &= \sigma\Bigl( \mathbf{W}_{ih}^{i}\,\mathbf{x}(t) + \mathbf{b}_{ih}^{i} + \mathbf{W}_{hh}^{i}\,\mathbf{h}(t-1) + \mathbf{b}_{hh}^{i} + \mathbf{p}^{i}\circ\mathbf{c}(t-1) \Bigr), \\[6pt] \mathbf{f}(t) &= \sigma\Bigl( \mathbf{W}_{ih}^{f}\,\mathbf{x}(t) + \mathbf{b}_{ih}^{f} + \mathbf{W}_{hh}^{f}\,\mathbf{h}(t-1) + \mathbf{b}_{hh}^{f} + \mathbf{p}^{f}\circ\mathbf{c}(t-1) \Bigr), \\[6pt] \mathbf{c}(t) &= \mathbf{f}(t)\,\circ\,\mathbf{c}(t-1) \;+\;\mathbf{i}(t)\,\circ\,\mathbf{z}(t), \\[6pt] \mathbf{o}(t) &= \sigma\Bigl( \mathbf{W}_{ih}^{o}\,\mathbf{x}(t) + \mathbf{b}_{ih}^{o} + \mathbf{W}_{hh}^{o}\,\mathbf{h}(t-1) + \mathbf{b}_{hh}^{o} + \mathbf{p}^{o}\circ\mathbf{c}(t) \Bigr), \\[6pt] \mathbf{h}(t) &= \mathbf{o}(t)\,\circ\,\tanh\bigl(\mathbf{c}(t)\bigr)\end{split}\]
Parameters:

  • input_size (int) – Number of input features \(\dim(\mathbf{x}(t))\).

  • hidden_size (int) – Number of hidden units \(\dim(\mathbf{h}(t))\).

  • bias (bool, optional) – If False, disables all biases \(\mathbf{b}_{ih}\) and \(\mathbf{b}_{hh}\). Default: True.

  • activation_fn (Callable, optional) – Activation for the cell candidate \(\mathbf{z}\). Default: torch.tanh.

  • gate_activation_fn (Callable, optional) – Activation for input/forget/output gates. Default: torch.sigmoid.

  • kernel_init (Callable, optional) – Initializer for input-to-hidden weights \(\mathbf{W}_{ih}\). Default: nn.init.xavier_uniform_.

  • recurrent_kernel_init (Callable, optional) – Initializer for hidden-to-hidden weights \(\mathbf{W}_{hh}\). Default: nn.init.xavier_uniform_.

  • peephole_kernel_init (Callable, optional) – Initializer for peephole weights \(\mathbf{p}\). Default: nn.init.normal_.

  • bias_init (Callable, optional) – Initializer for input biases \(\mathbf{b}_{ih}\) when bias=True. Default: nn.init.zeros_.

  • recurrent_bias_init (Callable, optional) – Initializer for hidden biases \(\mathbf{b}_{hh}\) when bias=True. Default: nn.init.zeros_.

  • device (torch.device, optional) – Device of the parameters. Default: CPU.

  • dtype (torch.dtype, optional) – Data type of the parameters. Default: PyTorch float.

Inputs: input, (h, c)

  • input (Tensor): shape (H_in,) or (N, H_in), where H_in = input_size.

  • h, c (Tensor): previous hidden and cell states of shape

    (H_out,) or (N, H_out), where H_out = hidden_size. If not provided, both default to zero.

Outputs: h’, c’

  • h’, c’ (Tensor): next hidden and cell states, same shapes as inputs.

Shape:

  • input: \((N, H_{\mathrm{in}})\) or \((H_{\mathrm{in}})\).

  • h, c: \((N, H_{\mathrm{out}})\) or \((H_{\mathrm{out}})\).

  • output: same as h and c.

Type:

bias_ih

input biases, shape (4*H,) if bias=True.

Type:

Tensor

bias_hh

hidden biases, shape (4*H,) if bias=True.

Type:

Tensor

Examples::
>>> cell = PeepholeLSTMCell(10, 20)
>>> x = torch.randn(5, 10)
>>> h, c = torch.zeros(20), torch.zeros(20)
>>> for t in range(x.size(0)):
...     h, c = cell(x[t], (h, c))
